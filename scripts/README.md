# scripts/

이 폴더는 `chore/v0.1.0-repository-foundation` 범위의 저장소 정책 점검 스크립트 골격을 담습니다.

## 실행 방법

```powershell
powershell -ExecutionPolicy Bypass -File scripts/check-repo-policy.ps1
```

## 검사 범주

- 금지 경로 점검: `.claude`, `.codex`, `.agents`, `.cursor`, `prompt-history`, `session-logs`, `agent-logs`, `scratchpad`
- 금지 파일 점검: `.env`, `.env.local`, `.env.development`, `.env.production`, `.env.test`, `CLAUDE.md`, `AGENTS.md`, `AI_NOTES.md`, `AI_LOG.md`, 비정상 확장자
- 금지 문자열 점검(대소문자 무시):
  `Co-authored-by`, `Signed-off-by`, `Generated by ChatGPT`, `Generated by Claude`, `Generated by Codex`, `Generated with AI`, `Assisted by AI`
- Secret 유사 패턴 점검: Private Key Header, 할당된 key/secret/token/password 값, 일반 credential 패턴
- 파일 크기 경고/실패: 5MB 경고, 10MB 실패
- Git 추적 기반 검사: `git ls-files`, `git diff --cached --name-only`
- Git 미초기화 모드: 파일 시스템 기반으로 경고만 출력하고 종료

## 경고·실패 기준

- 실패: 추적/스테이징 대상의 금지 파일, 금지 경로 파일, `.env` 실제 파일, 금지 문자열, Secret 유사 패턴, 10MB 초과 파일
- 경고: 5MB 초과(단, 10MB 미만) 파일
- 허용: `.env.example` 및 placeholder/예시 값(`replace-with-*`, `example`, `placeholder`, `dummy`, `test-only`)이 포함된 파일

## Git 초기화 전후 동작 차이

- Git 저장소인 경우: 추적 파일과 스테이징 파일만 검사 대상
- Git 저장소가 아닌 경우: Git 추적 상태 검사를 생략하고 파일 시스템 기준으로만 점검
- 메시지 예시:

```text
Git 저장소가 아직 초기화되지 않아 Git 추적 상태 검사는 생략했습니다.
파일 시스템 기준 정책 검사는 실행했습니다.
```

현재 범위 내에서는 `check-git-author.ps1`는 별도 보강 없이 유지합니다.
